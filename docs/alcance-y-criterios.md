# Alcance y criterios de BLOCKMATE

Actualizado el 2/11/2026. Los cambios de RAMA-VICTORIA se integraron en main (`38f2635`). La copia de trabajo incorpora después Memento para encapsular el estado que permite deshacer. El plan grupal organiza el trabajo; los acuerdos todavía no registrados se listan en [integridad y estado de revisión](integridad-y-cierre.md).

## Alcance

Ajedrez estándar local de 8 × 8, una persona contra IA o dos humanos, interfaz web y consola básica. Incluye reglas, historial, capturas, puntaje, deshacer/rehacer, guardado y reloj activo en la sesión web. [Requisitos y límites](requisitos.md).

El criterio comunicado por el docente exige que los diagramas coincidan con las clases del programa. No se dispone en esta documentación de una rúbrica completa que permita afirmar otros acuerdos docentes.
